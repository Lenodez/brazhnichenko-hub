# Brazhnichenko Hub — Планы развития (Roadmap)

## Отложенные идеи (напомнить по запросу)

### 1. Гибридный режим для Android / Fold 8: «Локальный офлайн-мозг + Удалённый ПК (RTX 4080)»
- **Идея:** в мобильном приложении `BrazhnichenkoHub-Android-arm64.apk` добавить переключатель источника вычислений в шапке:
  - **«На телефоне (Офлайн)»** — локальная `Qwen 3 4B` / `Qwen 2.5 VL 7B Vision` / `Gemma 3 12B` на Snapdragon (работает в самолёте, метро, без сети).
  - **«Домашний ПК (RTX 4080)»** — подключение с телефона к `LocalAIHub.CrossPlatform` на ПК по локальному Wi-Fi или через защищённый VPN/туннель (с авторизацией по токену), чтобы прямо с экрана Galaxy Z Fold 8 запускать тяжёлые 35B LLM, фото `FLUX 3 / Qwen-Image 2.1`, видео `Wan 2.2 / LTX-2.5` и смотреть Галерею ПК.

### 2. Единый релиз `v4.3.0` для Windows + публикация кроссплатформенных сборок на VPS
- Пересобрать `LocalAIHub-Setup.exe` (`v4.3.0`) с обновлённой базой знаний RAG (Apple Silicon M1–M6 + Linux).
- При желании выложить `macOS`, `Linux` и `Android APK` на VPS рядом с Windows-релизом (не затрагивая Windows `latest.json`).
